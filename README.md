# Kikoo Mobile Try-On

Research workspace for evaluating DM-VTON and Mobile-VTON on Android. The
Android prototype lives in [`android/`](android/); experiments and measured
reports are under [`experiments/`](experiments/) and [`reports/`](reports/).

## Recreate excluded model files

Large checkpoints, converted networks, native libraries, APKs, and build
outputs are intentionally excluded from Git. Download the original artifacts
into `/tmp` or `weights/`, then regenerate local exports.

### DM-VTON

- Source and release 1.0.0: <https://github.com/KiseKloset/DM-VTON/releases/tag/1.0.0>
- The official PF student checkpoints are `dmvton_pf_warp.pt` and
  `dmvton_pf_gen.pt`. Keep them outside Git, for example in `/tmp/`.
- Export Android MNN stages with `scripts/export_dm_vton_mnn.py`; the script
  reads those checkpoints and writes `experiments/2026-10-25-dm_vton/`.
- The VITON-Clean dataset is linked by the pinned DM-VTON README and Colab:
  <https://github.com/KiseKloset/DM-VTON/blob/5dcd04ee3f5b1fb392df1184c887c1a7e910c72e/README.md>

### Mobile preprocessing

Download MediaPipe Pose Landmarker Lite float16 v1 from:
<https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task>
Save it as `weights/mediapipe/pose_landmarker_lite.task`; its SHA256 and
packaging step are recorded in `android/app/src/main/assets/preprocess/model.json`.

Mobile-VTON source and weights are documented in
[`models/mobile_vton/README.md`](models/mobile_vton/README.md). Native MNN and
APK files are regenerated by `scripts/build_android_native.sh` and
`scripts/build_android_app.sh`; they are not repository inputs.

Run `python -m pytest -q` for the Python checks. Android validation commands
and Pixel 4 measurements are in [`android/README.md`](android/README.md).
